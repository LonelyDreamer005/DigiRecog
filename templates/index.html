Project Presentation Notes & Viva Preparation

Deep Learning CBP Course

Q1: What is the mathematical formulation of Softmax Regression?

Answer: Softmax Regression computes linear logits $z_k = \mathbf{w}_k^T \mathbf{x} + b_k$ for each digit class $k \in \{0, \dots, 9\}$. The Softmax function normalizes logits into class probabilities:

$$P(y = k \mid \mathbf{x}) = \frac{e^{z_k}}{\sum_{j=0}^{9} e^{z_j}}$$

Q2: Why does Softmax accuracy drastically collapse under a 2-pixel shift (from 91.4% to 34.25%)?

Answer: Softmax Regression treats every pixel in the $28 \times 28$ grid as an independent coordinate without spatial connectivity. It learns a single fixed weight for each coordinate $(i, j)$. Shifting by 2 pixels moves stroke pixels onto weights for background or other classes. In contrast, CNN utilizes convolutional weight sharing and Max Pooling, conferring spatial translation invariance ($84.70\%$ shifted accuracy).

Q3: Why is Otsu binarization and aspect-ratio bounding-box centering critical for digit recognition?

Answer: Real-world captures differ from MNIST (ink polarity, background lighting, varied drawn sizes). The preprocessing pipeline applies Otsu thresholding, extracts the stroke bounding box, scales the digit preserving aspect ratio to $20 \times 20$, and centers it on a $28 \times 28$ black canvas.

Q4: What is the loss function used and why?

Answer: Sparse Categorical Cross-Entropy: $$L = -\sum_{i=1}^{N} \log P(y_i \mid \mathbf{x}_i)$$ Using integer labels $\{0, \dots, 9\}$ rather than one-hot vectors saves memory and speeds up gradient computation.
